# Document Classification using NLP

An NLP-based machine learning project that automatically classifies documents into different topics using **TF-IDF, Naive Bayes, and Support Vector Machine (SVM)** algorithms.

## 📌 Project Overview

Document classification is a Natural Language Processing (NLP) task used to automatically categorize text documents into predefined classes.

This project preprocesses text data, converts text into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)**, and applies machine learning algorithms to classify documents into **5 different topics**.

## 🎯 Objectives

- Perform text preprocessing and cleaning.
- Convert text into numerical features using TF-IDF.
- Train machine learning classification models.
- Compare Naive Bayes and SVM performance.
- Classify documents into predefined topics.
- Build a simple and reproducible NLP classification pipeline.

## 🧠 Technologies Used

- Python
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy
- TF-IDF
- Multinomial Naive Bayes
- Support Vector Machine (SVM)
- Jupyter Notebook
